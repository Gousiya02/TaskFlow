# TaskFlow AI

AI-powered task management application built using React, Node.js, Express, MongoDB, and OpenAI/Gemini APIs.

## Features
- JWT Authentication
- AI-powered task suggestions
- Dashboard analytics
- Task CRUD operations
- Responsive UI

## Tech Stack
- React + Tailwind CSS
- Node.js + Express
- MongoDB Atlas
- OpenAI/Gemini API

## Setup

### Backend
cd server
npm install
npm run dev

### Frontend
cd client
npm install
npm run dev
